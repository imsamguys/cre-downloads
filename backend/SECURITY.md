# CRE security boundary

The public GitHub Pages site is static. Supabase Auth handles passwords and sessions; only its publishable key is present in the browser. All Studio tables force row-level security. Project policies scope reads and writes to `auth.uid()`. Browser roles cannot write media or render-job records, nor access the earlier automation tables or functions.

The Python API binds to `127.0.0.1` only. Every project and job request requires a Supabase bearer token, validates that token with Supabase Auth, and checks the project through the user's RLS-limited query. Local data is isolated by account and project UUID. Browser origins are allowlisted; uploads are rate-limited, streamed into quarantine, bounded by size, checked by extension and signature, and stored under content hashes. Approval validates the review snapshot before render. Downloads require the same project authorization. Errors sent to the browser do not include internal paths or provider responses.

The original Streamlit editor and local Open Reel bridge also have XSRF/origin checks, throttling, and upload validation. Keep them on loopback. Provider keys belong in local environment variables or ignored local secrets files. No payments, public media uploads, or remote rendering endpoint is active. The Stripe-style signature verifier is a tested helper for a future payment integration, not an active payment control.

The current loopback API uses in-memory rate limits and background tasks in one process. It is designed for local use, not deployment to a shared public server. A machine owner should protect their operating-system account and local media directory. The launch CI checks dependencies, builds the site, compiles Python, and runs tests. Security reports should use GitHub's private advisory channel.

CodeQL runs for both Python and JavaScript/TypeScript on every push. Its path-access findings were reviewed at the entry points: public API project and job path components are parsed as UUIDs; browser upload names are sanitized and checked against allowed suffixes and file signatures; Open Reel media IDs are confined to its media directory; review IDs are generated and validated; Format 1 template slugs are validated. The original desktop editor also lets its local operator select source files and movie folders on purpose. That editor must stay bound to loopback, as the launch commands specify. CodeQL findings for those intended or constrained paths are dismissed with the reason recorded on each alert; future scans remain enabled.
